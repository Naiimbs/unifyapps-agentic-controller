Standard Operating Procedure

Step-by-Step Execution Guide

From developer prompt to a published, brand-compliant, reusable module across any UnifyApps project.

1

API Gateway Client Authorization

OAuth2

Authenticate using the registered client Antigravity-Agent-Bridge (ID: 6aeaedcf41af9153531ebb1f) to obtain a Bearer Token for tenant API calls.

curl -X POST https://unifyapps-dev.modhs.med.sa/oauth/token \
  -d "client_id=6aeaedcf41af9153531ebb1f" \
  -d "grant_type=client_credentials"
2

Connect External AI Agent via MCP

Model Context Protocol

Configure the MCP server Antigravity-Unify-MCP in your AI tool (Antigravity, Cursor, Claude) to query live canvas AST and tools.

// Call MCP Tool
const { blocks } = await mcp.callTool('unify_get_page_blocks', {
  appId: 'media-center-app',
  pageSlug: 'myspace'
});
3

Delegate Layout Generation via A2A

A2A Protocol

Send a natural language layout request to the deployed A2A server Antigravity-Unify-A2A. UnifyApps' built-in App page builder generates the component tree.

POST /p/0/api-platform/collections/6aeaf23341af9153531ebb24/HandleJSONRPC
{ "method": "build_component", "params": { "prompt": "Create filter bar with search & date picker" } }
4

Surgical Block-Scoped CSS Injection

Zero Leakage

Inject custom CSS into Monaco scoped exclusively to [data-block-id='...'] and configure HTML attributes (dir="rtl").

[data-block-id='filters'] {
  background: #f8fafc;
  border: 1.6px solid #125939; /* Saudi MOD Green */
  border-radius: 12px;
}
5

Package as Reusable Cross-App Module

One-Click Reuse

Convert the validated block into a UnifyApps Template Component (appearing alongside DGA_Carousal). Every app across the organization can now drag-and-drop the pre-styled component.

unify_package_as_module({ blockId: 'filters', name: 'MODHS_Universal_FilterBar' });
